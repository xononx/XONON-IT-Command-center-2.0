# 🖥️ XONON-IT Command Center 2.0

A Windows desktop system administration and utility tool designed to put useful Windows and network tools in one place.

## ✨ Features

- 🖥️ Windows system tools
- 🌐 LAN / network utilities
- 🔎 IP and hostname discovery
- ⚡ Quick administration tools
- 🔧 System utilities
- 🎨 Modern desktop interface

## 📥 Download

The latest version is **XONON-IT Command Center 2.0 (v2.0.0)**.

Download the Windows installer from the **Releases** section of this repository.

Installer:
`XONON-IT-Command-Center-2.0-Setup.exe`

## 💻 Requirements

- Windows 10 or Windows 11
- Some administration features require Administrator privileges
- Network-related tools should only be used on systems and networks you are authorized to administer

2. Open the installer.
3. Follow the installation instructions.
4. Launch XONON-IT Command Center 2.0.
